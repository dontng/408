这是一个非常核心的考点，贯穿了数据结构“树”这一章的始终，并且是图论中关于树的判定的基础。

我们来深入探讨一下树的结点（Nodes, $N$）和边（Edges, $E$）的关系及其推论。



### 1. 核心关系：$E = N - 1$



在数据结构中，一棵非空的树（Tree）被定义为一个包含 $N$ 个结点的有限集合，其中：

1. 有且仅有一个特定的结点称为**根（Root）**。
2. 当 $N > 1$ 时，其余结点可分为 $m$ ($m \ge 0$) 个互不相交的有限集合 $T_1, T_2, \dots, T_m$，其中每一个集合本身又是一棵树，并称为根的**子树（Subtree）**。

从这个定义中，我们可以推导出结点与边的关系：

**推导过程（基于数据结构定义）：**

1. **定义：** 树中的“边”是连接父结点和子结点的线。
2. **观察：**
   - 根结点（Root）是唯一没有父结点的结点。
   - 除根结点外的所有其他结点，都有且仅有一个父结点。
3. **结论：** 树中的每一条边都唯一地对应一个“非根结点”（即，这条边就是连接该结点与其父结点的线）。
4. **因此：** 边的总数（$E$）必须等于非根结点的总数。
5. **公式：** 如果总结点数是 $N$，非根结点的数量就是 $N - 1$。
6. **所以：$E = N - 1$**

**一句话总结：树中除了根结点外，每个结点都有一条指向它的入边（即连接其父结点的边），所以 $N$ 个结点必然有 $N-1$ 条边。**

------



### 2. 核心推论（408考点）



这个 $E = N - 1$ 的关系非常强大，是解决许多计算问题和证明题的基础。



#### 推论 1：图论中“树”的判定（非常重要）



在图论中，一个无向图 $G$ 是一棵树，当且仅当它满足以下三个条件中的任意两个（满足两个，第三个必成立）：

1. $G$ 是**连通的**（Connected）。
2. $G$ 是**无环的**（Acyclic）。
3. $G$ 拥有 $N$ 个顶点和 $N - 1$ 条边（即 $E = N - 1$）。

**408中常见的判定推论：**

- **推论 1a (连通 + $N-1$ 边 $\Rightarrow$ 无环):** 一个有 $N$ 个顶点的连通图，如果它有 $N-1$ 条边，那么它必定是一棵树（必定无环）。
  - *（反证法：如果它有环，要保持连通，至少需要 $N$ 条边。）*
- **推论 1b (无环 + $N-1$ 边 $\Rightarrow$ 连通):** 一个有 $N$ 个顶点的无环图，如果它有 $N-1$ 条边，那么它必定是一棵树（必定连通）。
  - *（反证法：如果不连通，它就是一个森林，假设有 $k$ 个连通分量（$k>1$），则总边数为 $E = N - k$。这与 $E = N - 1$ 矛盾。）*



#### 推论 2：森林（Forest）的边与结点关系



森林是 $k$ 棵互不相交的树的集合（$k \ge 0$）。

- 假设森林 $F$ 共有 $N$ 个结点， $E$ 条边，由 $k$ 棵树组成。
- 第 $i$ 棵树有 $N_i$ 个结点，则它有 $E_i = N_i - 1$ 条边。
- 总结点 $N = N_1 + N_2 + \dots + N_k$
- 总边数 $E = E_1 + E_2 + \dots + E_k$
- $E = (N_1 - 1) + (N_2 - 1) + \dots + (N_k - 1)$
- $E = (N_1 + N_2 + \dots + N_k) - (1 + 1 + \dots + 1)$ （共 $k$ 个 1）
- **$E = N - k$**

结论： 对于一个包含 N 个结点和 k 个连通分量（k 棵树）的森林，其边数 E=N−k。

（这个公式是 E=N−1 的推广，当 k=1 时，森林就是一棵树，E=N−1）。



#### 推论 3：结点度数（Degree）的关系



这个推论是 $E = N - 1$ 的一个极其重要的应用，尤其在二叉树中。

**A. 任意树（基于数据结构：度 = 孩子数 = 出度）**

- $N_k$ 表示度为 $k$ 的结点数量（即有 $k$ 个孩子的结点）。
- $N_0$ 是叶子结点（度为 0）的数量。
- $N$ 是总结点数：$N = N_0 + N_1 + N_2 + \dots$
- $E$ 是总边数：边是由“非叶子结点”贡献的。一个度为 $k$ 的结点贡献 $k$ 条边（连接它的 $k$ 个孩子）。
- $E = (1 \cdot N_1) + (2 \cdot N_2) + (3 \cdot N_3) + \dots = \sum_{k \ge 1} (k \cdot N_k)$

现在我们联立两个核心公式：

1. $E = N - 1$
2. $E = N_1 + 2N_2 + 3N_3 + \dots$

将 N=N0+N1+N2+… 代入 (1)：

E=(N0+N1+N2+…)−1

现在让两个 E 相等：

(N0+N1+N2+N3+…)−1=N1+2N2+3N3+…

移项整理：

N0−1=(N1−N1)+(2N2−N2)+(3N3−N3)+…

N0−1=N2+2N3+3N4+⋯+(m−1)Nm

**$N_0 = 1 + N_2 + 2N_3 + 3N_4 + \dots$**

**结论：** 在任意树中，叶子结点的数量（$N_0$）比“度为2的结点数 + 2倍度为3的结点数 + ...”多 1。

**B. 二叉树的特例（408 必考推论）**

二叉树是一种特殊的树，其结点的度 k 只能取 0、1、2。

即 N3,N4,… 均为 0。

将这个条件代入上面的通用公式：

N0=1+N2+2(0)+3(0)+…

**$N_0 = N_2 + 1$**

**核心结论：** 在任何非空二叉树中，叶子结点（$N_0$，度为0的结点）的数量，必定比度为 2 的结点（$N_2$）的数量多 1。

- *这个推论与 $N_1$（度为1的结点）的数量无关。*
- *408选择题经常会问：一棵二叉树有 $x$ 个叶子结点，则其度为2的结点有多少个？答案就是 $x-1$。*



#### 推论 4：图论中的度数和（Sum of Degrees）



在图论中（将树视为无向图），“度”是指连接该结点的总边数。

- 图论基本定理：所有顶点的度数之和等于边数的 2 倍。

  ∑degree(vi)=2E

- 将 E=N−1 代入：

  ∑i=1Ndegree(vi)=2(N−1)

**结论：** 在一棵 $N$ 个结点的树中（$N \ge 1$），所有结点的度数之和为 $2N - 2$。

- *（注意：这里的“度”是图论的度，不是数据结构中“孩子数量”的度。例如，一个叶子结点，在数据结构中度为0，但在图论中度为1（连接父结点）。根结点在数据结构中度为 $k$（孩子数），在图论中度也为 $k$。）*



### 总结



对于408备考，你需要牢牢记住以下几点：

1. **基本关系：** $N$ 个结点的树，有 $E = N - 1$ 条边。
2. **森林推广：** $N$ 个结点、$k$ 棵树的森林，有 $E = N - k$ 条边。
3. **图论判定：** “连通”、“无环”、“$E = N - 1$”，三者知二推一。
4. **二叉树推论：** $N_0 = N_2 + 1$ （叶子结点比度为2的结点多1）。这是 $E = N - 1$ 结合二叉树度数特性推导出来的。
